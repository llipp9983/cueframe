# CUEFRAME

방송 시작 전에 보여 주는 **대기화면**을 만드는 Windows 프로그램입니다. 배경·테이블·소품·문구·카운트다운·채팅창을 올려 화면을 꾸미고, 방송용 출력 창을 OBS에 캡처해서 씁니다. 치지직, YouTube, SOOP의 라이브 채팅을 채팅창에 바로 띄울 수 있습니다.

Electron + React + Vite (JavaScript)

## 설치와 실행

### 설치 파일로 쓰기

[Releases](https://github.com/llipp9983/cueframe/releases)에서 `CUEFRAME-<버전>-win-x64.exe`를 받아 설치합니다. 설치한 프로그램은 새 버전이 나오면 스스로 알려 줍니다.

### 소스에서 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 모드 (Vite + Electron)
npm start        # 빌드한 뒤 실행
npm test         # 단위 테스트 (Vitest)
npm run dist     # Windows 설치 파일(NSIS)과 zip 만들기
```

## 처음 써 보기

1. **[파일] > [템플릿으로 새 프로젝트…]** 에서 마음에 드는 대기화면을 고릅니다. 배경, 테이블, 소품, 문구, 채팅창, 분위기 효과가 한 번에 만들어지고 장면이 2개("대기 중", "곧 시작") 들어 있습니다.
2. 카운트다운 시각과 문구를 바꾸고, 소품은 끌어서 옮깁니다.
3. 화면 오른쪽 아래 **[채팅 연결]** 버튼으로 채팅을 연결합니다.
4. **[출력 창 열기]** 를 누르고 OBS에서 창 캡처로 "방송 출력 창"을 고릅니다.

도움말 메뉴의 **시작하기 안내**에 그림이 들어 있는 안내가 있습니다.

## 주요 기능

**화면 꾸미기**
- 템플릿 10종: 별빛 밤하늘, 벚꽃 카페, 네온 도시, 민트 룸, 노을 해변, 미니멀 다크, 아케이드 나이트, 눈 오는 오두막, 아쿠아리움, 가을 숲. 모든 그림은 이 프로그램을 위해 직접 그린 것입니다.
- 배경(이미지·영상), 테이블, 소품(여러 개 한 번에), 좌우 반전, 끌어서 이동·크기·회전
- 문구·시계·카운트다운, 글꼴 선택(내장 5종 + 내 PC에 설치된 글꼴)
- 레이어 효과: 그림자, 빛나기, 둥실둥실, 흔들림, 숨쉬기, 천천히 돌기, 흐리게, 어둡게
- 분위기 효과 레이어: 눈, 꽃잎, 별, 하트, 반짝이, 거품
- 정렬 버튼, 스냅, 단축키, 레이어 이름 바꾸기(F2), 끌어서 순서 바꾸기, 잠금·숨김
- 되돌리기·다시 실행, 1분마다 자동 저장과 비정상 종료 후 복구

**채팅창**
- 프리셋 16종과 내 프리셋 저장·가져오기·내보내기
- 말풍선, 닉네임, 방송인 메시지 강조, 왕관, 이미지·도형 장식, 글꼴
- **채팅창 배경 그림**: PNG·JPG를 채팅 영역 뒤에 깔고 꽉 채우기·전체 보이기·타일 반복, 투명도를 고를 수 있습니다. 프로젝트를 저장하면 그림 파일이 프로젝트의 `media` 폴더로 복사됩니다.
- 치지직 이모티콘, YouTube 채널 이모지 이미지 표시
- **기본값으로 초기화** 버튼으로 채팅창 설정을 처음 상태로

**방송**
- 장면 최대 20개, 방송에 내보낼 장면을 따로 고르기
- 장면 전환 효과 9종, 해상도 1920×1080 / 1280×720, 30·60fps
- 치지직 위젯(후원 알림, 영상 후원) 레이어

**초기화 버튼**
- 레이어 **모양 초기화**(회전·투명도·좌우 반전), **효과 모두 끄기**
- 문구 **글자 모양 초기화**(내용과 카운트다운 시각은 그대로)
- 채팅창 **기본값으로 초기화**
- **[도움말] > [화면 설정 초기화…]**: 접어 둔 패널, 마지막 폴더 같은 화면 설정만 되돌립니다. 프로젝트, 채팅 연결 키, 로그인 정보는 건드리지 않습니다.

## 채팅 연결

| 플랫폼 | 방식 | 필요한 것 |
| --- | --- | --- |
| 치지직 | 공식 API | 치지직 개발자센터에서 만든 Client ID·Secret, 네이버 로그인 |
| YouTube (간편) | 공개 채팅 읽기 (비공식) | 방송 주소, 영상 ID, 또는 @채널 이름. 로그인·키 필요 없음 |
| YouTube (공식 API) | YouTube Data API v3 | 구글 클라우드에서 만든 OAuth 클라이언트(데스크톱 앱), 로그인 |
| SOOP | 시청자 채팅 읽기 (비공식) | 방송인 ID 또는 방송 주소. 로그인 필요 없음 |

- **모두 읽기 전용**입니다. 채팅을 보내거나 방송에 손대지 않습니다.
- 치지직 키, YouTube 인증 정보는 `safeStorage`로 이 PC에 암호화되어 저장되고 화면(렌더러)에는 전달되지 않습니다.
- 여러 플랫폼을 동시에 연결할 수 있고, 채팅은 하나의 채팅창에 섞여 나옵니다.
- **YouTube 간편 연결**: 시청자가 보는 것과 같은 공개 채팅 주소를 읽습니다. 슈퍼챗, 슈퍼스티커, 멤버십 가입·선물 알림, 채널 이모지를 보여 줍니다. [YTLiveChat](https://github.com/Agash/YTLiveChat)의 방식을 참고했습니다. `@채널` 주소로 연결하면 방송이 시작될 때까지 기다립니다.
- **YouTube 공식 API**: 구글이 정한 하루 사용량(기본 10,000 단위)을 쓰며 화면에서 사용량을 볼 수 있습니다. 간편 연결이 막혔을 때의 대비책입니다.
- **SOOP**: 시청자가 접속하는 채팅 서버에 익명으로 접속합니다. 별풍선은 문구로 표시하고, 19세 이상·비밀번호 방송은 지원하지 않습니다. [soopapi](https://github.com/getCurrentThread/soopapi)의 프로토콜 설명을 참고했습니다.

> **주의** YouTube 간편 연결과 SOOP은 공식 API가 아닙니다. 서비스가 화면 구조나 채팅 서버 방식을 바꾸면 예고 없이 안 될 수 있고, 서비스 약관상 허용 범위는 직접 확인하세요. 방송에서 꼭 필요하면 공식 API 방식을 쓰는 것이 안전합니다.

## 장면과 전환 효과

위쪽 탭이 장면입니다. 방송에 나가는 장면이 바뀔 때 **[⚙ 출력 설정] > 장면 전환**의 효과가 쓰입니다.

페이드 · 밀기(4방향) · 줌 · 흐려지며 전환 · 닦아내기 · 바로 바꾸기

템플릿마다 어울리는 전환이 정해져 있습니다(예: 아케이드 나이트는 닦아내기, 눈 오는 오두막은 흐려지며 전환, 아쿠아리움은 줌, 가을 숲은 밀기). 시작한 뒤에는 자유롭게 바꿀 수 있습니다.

## OBS에 넣기

1. **[출력 창 열기]** 를 누릅니다.
2. OBS 소스에서 **[창 캡처]** 를 추가하고 `[CUEFRAME.exe]: 방송 출력 창`을 고릅니다.
3. 캡처 방식은 `Windows 10 (1903 이상)`, 커서 캡처는 끕니다.
4. 최소화하면 화면이 멈추므로, 출력 창의 `-` 버튼(화면 밖으로 숨기기)을 쓰세요.

출력 해상도는 OBS 캔버스와 같게 맞추면 가장 선명합니다.

## 빌드와 배포

```bash
npm run dist
```

`release/` 폴더에 `CUEFRAME-<버전>-win-x64.exe`(설치 파일), `.exe.blockmap`, `latest.yml`, zip이 만들어집니다. 템플릿 그림(`assets/templates`)은 설치 폴더의 `resources/templates`로 들어갑니다.

템플릿 그림을 다시 만들려면:

```bash
node scripts/gen-templates.mjs
```

## 폴더 구조

```
electron/   메인 프로세스: 창, IPC, 파일 저장, 암호화 보관, 치지직·YouTube·SOOP 연결, 자동 업데이트, 로그
src/core/   화면과 무관한 순수 함수: 레이어·장면·프로젝트 읽기/쓰기, 채팅 설정·프리셋,
            채팅 변환(chzzk·youtube·ytweb·soop), 전환 효과, 템플릿 정의
src/renderer/
  editor/   편집기 (레이어 목록, 미리보기, 속성 패널, 하단 막대)
  output/   방송 출력 창 (장면 전환 포함)
  scene/    미리보기와 출력 창이 함께 쓰는 장면·채팅창 컴포넌트
  dialogs/  채팅 연결, 템플릿 선택, 안내, 확인·이름 입력 창
  theme/    디자인 토큰, 컨트롤 스타일, 아이콘
assets/templates/   템플릿 그림 (scripts/gen-templates.mjs 로 생성)
public/guide/       시작하기 안내 그림
scripts/            그림·글꼴 생성 스크립트
tests/              단위 테스트
```

## 데이터가 저장되는 곳

- `%AppData%\StandbyScreen` — 최근 프로젝트, 채팅 프리셋, 설정(`settings.json`), 자동 저장, 로그
- `%LocalAppData%\StandbyScreen` — 암호화된 키·로그인 정보(`*.bin`)
- 프로젝트 — 직접 고른 폴더(`project.json` + `media/`)

프로젝트, 키, 로그인 정보는 저장소에 올라가지 않습니다.

## 자동 업데이트

설치 파일(.exe)로 설치한 경우에만 동작합니다. 올릴 곳은 `package.json`의 `build.publish`에서 정합니다(지금은 이 저장소의 GitHub 릴리즈). 새 버전은 `.exe`, `.exe.blockmap`, `latest.yml`을 릴리즈에 올리면 설치된 앱이 알려 줍니다. 확인에 실패하면 로그에만 남습니다. zip 버전은 자동 업데이트가 되지 않습니다.

## 알려진 한계

- Windows 전용입니다. 출력 창은 OBS 창 캡처로 가져갑니다.
- YouTube 간편 연결과 SOOP은 비공식 방식이라 예고 없이 안 될 수 있습니다(위 주의 참고).
- SOOP은 19세 이상·비밀번호 방송과 이모티콘 이미지를 지원하지 않습니다.
- 채팅 연결 키는 PC마다 따로 입력해야 합니다(암호화되어 그 PC에서만 풀립니다).
- 코드 서명이 없어서 설치할 때 Windows SmartScreen 경고가 나올 수 있습니다.

## 개발 메모

- 시험용 가짜 서버 주소(`CUEFRAME_YT_*`, `CUEFRAME_YTWEB_BASE`, `CUEFRAME_SOOP_*`)는 **포장되지 않은 개발 실행에서 `CUEFRAME_TEST=1`일 때만** 쓰입니다. 설치한 앱에서는 동작하지 않습니다.
- 외부 주소는 허용 목록(정확한 호스트 이름 비교)으로만 엽니다. 위젯·이모지 이미지 주소는 https와 허용된 호스트만 받습니다.
- `ws`(MIT) 패키지로 SOOP 채팅 서버에 접속합니다. 오픈소스 고지는 [도움말] > [정보]에 있습니다.
