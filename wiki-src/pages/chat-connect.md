# 채팅 연결 (로그인)

채팅을 연결하면 채팅창에 실제 채팅이 나오고, **후원 알림**도 이 연결에 딸려 옵니다. 화면 오른쪽 아래 **[채팅 연결하기]** 를 누르면 연결 창이 열립니다. 위쪽 탭에서 플랫폼을 고릅니다.

:::summary 어떤 걸 해야 하나요?
- **치지직**: 앱 키 만들기(처음 한 번, 약 10분) + 로그인. 권한에 **후원 조회**를 꼭 포함
- **YouTube**: 주소만 넣으면 끝(간편) / 안정적으로 쓰려면 공식 API
- **SOOP**: 방송인 ID만 넣으면 끝
- 모두 **읽기 전용**, 키는 **내 PC에만 암호화** 저장
:::


| 플랫폼 | 필요한 것 | 걸리는 시간 |
|---|---|---|
| **치지직** | 개발자센터에서 앱 만들기(처음 한 번) + 네이버 로그인 | 약 10분 |
| **YouTube (간편)** | 방송 주소, 영상 ID 또는 @채널 이름 (로그인·키 없음) | 1분 |
| **YouTube (공식 API)** | 구글 클라우드의 OAuth 클라이언트 + 구글 로그인 | 약 15분 |
| **SOOP** | 방송인 ID 또는 방송 주소 (로그인 없음) | 1분 |

- 연결은 모두 **읽기 전용**입니다.
- 여러 플랫폼을 **동시에** 연결할 수 있고, 채팅은 한 채팅창에 섞여 나옵니다.
- 키와 로그인 정보는 이 PC에 **암호화되어 저장**되며 다른 곳으로 보내지지 않습니다. 단, **다른 PC에서는 다시 입력**해야 합니다.

## 치지직

치지직은 **내가 직접 앱 키를 만들어야** 합니다(처음 한 번).

### 1. 개발자센터에서 앱 만들기

1. **[치지직]** 탭의 **[치지직 개발자센터 열기 ↗]** 를 눌러 네이버 계정으로 로그인합니다.
2. **[애플리케이션 등록]** 으로 새 앱을 만듭니다. 이름은 자유롭게 정합니다.
3. **로그인 리디렉션 URL** 에 아래 주소를 **정확히** 넣습니다. CUEFRAME 창의 **[복사]** 버튼으로 복사해서 붙여 넣으면 틀리지 않습니다.

```
http://localhost:51789/callback
```

4. **API 권한(Scope)** 에서 두 가지를 **모두** 선택합니다.
   - **채팅 메시지 조회**
   - **후원 조회** ← 없으면 채팅은 보여도 **후원 알림이 오지 않습니다**
5. 등록이 끝나면 **Client ID** 와 **Client Secret** 이 나옵니다. Client Secret은 남에게 보여 주지 마세요.

![치지직 탭: 앱 키 입력 화면](img/link-chzzk.png)

### 2. 키 넣기

위 화면의 **Client ID**, **Client Secret** 칸에 붙여 넣고 **[저장하고 다음으로]** 를 누릅니다.

### 3. 로그인하고 연결

**[치지직 로그인]** 을 누르면 브라우저가 열립니다. 로그인하고 **[허용]** 을 누르면 자동으로 돌아오고, 상태가 **"연결됨"** 이 됩니다. 처음이 아니라면 **[채팅 연결]** 만 누르면 됩니다.

![치지직 탭: 로그인 단계](img/link-chzzk-login.png)

> **주의** **"연결됨 (후원 알림 권한 없음)"** 이라고 나오면 "후원 조회" 권한을 켜지 않은 것입니다. 개발자센터의 내 애플리케이션에서 권한을 켠 뒤 치지직을 **다시 연결**하세요.

## YouTube

### 간편 연결 (권장)

**[간편 연결]** 을 고르고 칸에 방송 주소, 영상 ID, 또는 `@채널이름`을 넣은 뒤 **[연결]** 을 누릅니다. `@채널이름`은 방송이 시작될 때까지 기다렸다가 자동으로 붙습니다. **[프로그램을 켤 때 자동으로 연결]** 을 켜 둘 수 있습니다.

![YouTube 탭: 간편 연결](img/link-youtube.png)

> **주의** 간편 연결은 시청자가 보는 공개 채팅을 읽는 **비공식 방식**입니다. YouTube가 화면 구조를 바꾸면 예고 없이 안 될 수 있습니다. 방송에서 꼭 필요하면 **공식 API**를 쓰세요.

### 공식 API

1. **[공식 API]** 를 고르고 **[Google Cloud 콘솔 열기 ↗]** 로 로그인해 **새 프로젝트**를 만듭니다.
2. **API 및 서비스 ▸ 라이브러리**에서 **YouTube Data API v3** 를 **사용**으로 켭니다.
3. **OAuth 동의 화면**을 **외부**로 만들고 **게시 상태를 "프로덕션"** 으로 바꿉니다. (테스트 상태로 두면 7일마다 다시 로그인해야 합니다)
4. **사용자 인증 정보 ▸ OAuth 클라이언트 ID 만들기**에서 종류를 **데스크톱 앱**으로 고릅니다.
5. **클라이언트 ID**, **보안 비밀**을 CUEFRAME에 붙여 넣고 **[YouTube 로그인]** 으로 구글 계정을 허용합니다.

구글이 정한 하루 사용량(기본 10,000 단위)을 쓰며, 연결 창에서 사용량을 볼 수 있습니다.

## SOOP

**[SOOP]** 탭에서 **방송인 ID** 또는 **방송 주소**(`https://play.sooplive.com/방송인ID`)를 넣고 **[연결]** 을 누릅니다. 방송 중인 채널에만 연결되고, 방송이 아직 시작되지 않았다면 몇 초 간격으로 다시 확인합니다.

![SOOP 탭](img/link-soop.png)

> **주의** SOOP도 **비공식 방식**입니다. 19세 이상·비밀번호 방송은 지원하지 않고, SOOP이 방식을 바꾸면 안 될 수 있습니다.

## 연결됐는지 확인

- 오른쪽 아래 채팅 상태 칩이 **"연결됨"** 인지 봅니다.
- 채팅창에 실제 채팅이 나오는지 봅니다.
- 후원은 [후원 알림](donation.md)의 확인 방법을 보세요.

## 연결을 끊고 싶을 때

연결 창의 **[연결 끊기]**, **[로그아웃]** 을 누릅니다. 저장된 앱 키를 바꾸려면 **[앱 키 바꾸기]** 입니다.
