# 효과와 움직임

## 레이어 효과

요소를 고르고 오른쪽 **[효과]** 를 엽니다. 움직임은 **버튼 한 번**으로 켜고 끕니다.

![효과 패널: 움직임 버튼](img/effects-panel.png)

**둥실둥실 · 반짝반짝 · 숨쉬기 · 살랑살랑 · 천천히 돌기 · 옆으로 흐르기** 중 하나를 누르면 알맞은 값으로 켜집니다. 같은 버튼을 다시 누르면 꺼집니다. 값을 직접 정하려면 **[움직임 세밀하게 조절]** 을 여세요. 아래 표는 각 효과의 모양입니다.

| 효과 | 모양 |
|---|---|
| 그림자 | 아래에 그림자가 생깁니다. |
| 빛나기 | 주변이 은은히 빛납니다. |
| 둥실둥실 | 위아래로 천천히 떠다닙니다. |
| 흔들림 | 좌우로 살짝 흔들립니다. |
| 숨쉬기 | 커졌다 작아졌다 합니다. |
| 천천히 돌기 | 제자리에서 돕니다. |
| **반짝반짝** | 별·불빛이 깜박입니다. |
| **옆으로 흐르기** | 구름·파도처럼 한 방향으로 흐릅니다. |
| 흐리게 | 뿌옇게 보이게 합니다. |
| 어둡게 | 밝기를 낮춥니다. |

**[효과 모두 끄기]** 로 한 번에 끌 수 있습니다.

> **팁** 한 요소에 효과를 너무 많이 겹치면 화면이 복잡해 보이고 PC도 힘들어합니다. 한두 개로 시작하세요.

## 분위기 효과 레이어

**[＋ 추가] ▸ [분위기 효과]** 로 화면 전체에 눈, 꽃잎, 별, 하트, 반짝이, 거품을 흩날리게 합니다. 종류, 개수, 크기, 떨어지는 시간, 좌우 흔들림, 색, 방향(위→아래 / 아래→위)을 고릅니다.

## 성능이 걱정될 때

- 큰 영상 배경과 많은 효과를 동시에 쓰면 PC가 느려질 수 있습니다.
- **[⚙ 출력 설정]** 에서 프레임 수를 30fps로 두면 부담이 줄어듭니다.
- 아래 **[진단 표시]** 를 켜면 출력 창의 실제 fps를 볼 수 있습니다.
