# 요소 추가하기

왼쪽 아래 **[＋ 추가]** 메뉴에서 요소를 넣습니다.

:::summary 한눈에 보기
- 모든 요소는 왼쪽 아래 **[＋ 추가]** 에서
- 요소를 클릭하면 **오른쪽에 설정**이 나옵니다
- **Ctrl+D** 복제, **Delete** 삭제, **Ctrl+Z** 되돌리기
:::


![추가 메뉴](img/add-menu.png)

| 메뉴 | 설명 |
|---|---|
| **배경 설정…** | 이미지나 영상을 배경으로 정합니다. |
| **테이블 추가…** | 소품을 올려 둘 테이블입니다. |
| **소품 추가…** | 여러 개를 한 번에 고를 수 있습니다. 소품은 테이블 윗면에 자동으로 붙습니다. |
| **채팅창 추가** | 라이브 채팅이 나오는 창입니다. ([채팅창 꾸미기](chat-style.md)) |
| **문구** | 글자를 넣습니다. |
| **시계** | 현재 시각입니다. |
| **카운트다운** | 방송 시작까지 남은 시간입니다. 시작 시각을 정해 둡니다. |
| **분위기 효과** | 눈, 꽃잎, 별, 하트, 반짝이, 거품이 떨어지거나 떠다닙니다. |
| **후원 알림 칸** | 후원이 들어오면 알림이 뜨는 자리입니다. ([후원 알림](donation.md)) |
| **위젯 주소 넣기…** | 치지직·SOOP 위젯 주소를 넣어 그대로 띄웁니다. (예전 방식. 후원은 가능하면 **후원 알림 칸**을 쓰세요) |

## 요소 고르고 다루기

- 미리보기에서 요소를 **클릭**하면 오른쪽에 설정이 나옵니다. **Ctrl+클릭**으로 여러 개를 고를 수 있고, **Ctrl+A** 는 모두 선택입니다.
- **위치와 크기**: 숫자로 정확히 넣을 수 있습니다.
- **모양**: 투명도, 회전, 좌우 반전(소품·테이블은 **Ctrl+H**). **[모양 초기화]** 로 회전·투명도·반전만 되돌립니다.
- **복제**: **Ctrl+D**. 삭제: **Delete**.
- **이미지 파일을 미리보기로 끌어다 놓아도** 요소로 추가됩니다.

## 문구와 글꼴

- 문구, 시계, 카운트다운은 글꼴, 크기, 색을 고릅니다.
- 글꼴은 내장 9종과 **내 PC에 설치된 글꼴**을 쓸 수 있습니다. 영문 제목용으로 Orbitron, Press Start 2P, Bungee, Fredoka가 들어 있습니다.
- **[글자 모양 초기화]** 는 내용과 카운트다운 시각은 그대로 두고 모양만 되돌립니다.

## 파일을 찾을 수 없다고 나올 때

이미지·영상 파일을 옮기거나 지우면 아래 막대에 **"⚠ 파일 N개 없음"** 이 뜹니다. 누르면 그 요소가 선택되고, 설정에서 **[파일 다시 연결…]** 로 다시 지정합니다. 프로젝트를 **저장**하면 그림 파일이 프로젝트 폴더의 `media`로 복사되어 이런 일이 줄어듭니다.
