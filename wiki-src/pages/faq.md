# 자주 묻는 질문

## 일반

### 어떤 PC에서 되나요?
Windows 전용 프로그램입니다. 구매·이용 조건은 판매자에게 문의하세요.

### 방송 송출도 해 주나요?
아니요. 대기화면을 만들고 **출력 창**을 제공할 뿐이고, 송출은 OBS 같은 프로그램이 합니다. ([OBS에 넣기](obs.md))

### 인터넷이 필요한가요?
대기화면을 만드는 데는 필요 없습니다. 인터넷은 **채팅·후원을 가져올 때**(연결했을 때만)와 **업데이트 확인**에만 씁니다.

### 내 로그인 정보는 안전한가요?
키와 로그인 정보는 **내 PC 안에서 암호화**되어 저장되고, 판매자나 다른 곳으로 보내지지 않습니다. 로그에서도 가려집니다. 연결은 **읽기 전용**이라 채팅을 보내거나 방송 설정을 바꾸지 못합니다. 단, 화면 캡처나 방송에 **Client Secret을 보여 주지 마세요.**

## 채팅·후원

### 치지직 앱 키를 꼭 만들어야 하나요?
네. 치지직은 공식 API만 쓰므로 내 앱 키(Client ID/Secret)가 필요합니다. 처음 한 번만 만들면 됩니다. ([채팅 연결](chat-connect.md))

### YouTube·SOOP은 로그인 없이 되는 게 안전한가요?
**비공식 방식**이라 서비스가 화면 구조나 채팅 서버를 바꾸면 예고 없이 안 될 수 있고, 서비스 약관상 허용 범위는 직접 확인하세요. 방송에서 꼭 필요하면 YouTube는 **공식 API** 방식을 쓰세요.

### 치지직·SOOP 후원의 소리와 TTS는 어떻게 하나요?
각 방송 사이트의 위젯이 가진 소리·TTS 기능을 쓰시고, 이 프로그램의 소리 기능은 **YouTube 후원에만** 적용됩니다.

### 후원 기록을 엑셀로 볼 수 있나요?
네. **[후원 기록 내보내기(CSV)]** 를 쓰세요. ([후원 알림](donation.md))

### 여러 플랫폼을 동시에 연결해도 되나요?
네. 채팅은 한 채팅창에 섞여 나옵니다.

## 화면

### 내 이미지·영상을 써도 되나요?
네. 배경은 이미지·영상, 소품·장식은 PNG·JPG를 쓸 수 있습니다. 저작권이 있는 자료는 직접 사용 권한을 확인하세요.

### 템플릿에 들어 있는 그림은 방송에 써도 되나요?
기본 템플릿의 그림은 이 프로그램을 위해 직접 그린 것입니다. 사람·캐릭터·동물은 없습니다.

### 다른 사람이 만든 템플릿을 써도 되나요?
`.cftemplate` 파일을 **[템플릿 파일 가져오기…]** 로 가져옵니다. 가져올 때 형식과 값을 모두 다시 검사하고, 파일에는 키·로그인 정보가 들어가지 않습니다. 출처를 아는 파일만 쓰세요.

### 장면은 몇 개까지 되나요?
20개입니다.

## 알려진 한계

- Windows 전용이며, 출력은 OBS **창 캡처**로 가져갑니다.
- YouTube 간편 연결과 SOOP은 **비공식** 방식입니다.
- SOOP은 19세 이상·비밀번호 방송, 이모티콘 이미지를 지원하지 않습니다.
- 앱 키·로그인은 PC마다 따로 입력합니다.
- 코드 서명이 없어 설치할 때 Windows 경고가 나올 수 있습니다. ([설치와 Windows 경고](install.md))
- 실제 방송에서의 후원 알림은 플랫폼 사정에 따라 달라질 수 있습니다. 방송 전에 **[알림 시험]** 으로 모양을 확인하고, 연결 상태를 점검하세요.
