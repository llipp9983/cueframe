# 저장·복구·데이터 위치

## 프로젝트 저장

- **Ctrl+S** 저장, **Ctrl+Shift+S** 다른 이름으로 저장, **Ctrl+O** 열기, **Ctrl+N** 새 프로젝트.
- 프로젝트는 **직접 고른 폴더**에 저장됩니다. 폴더 안에 `project.json`과 `media` 폴더(그림·영상)가 만들어집니다. 프로젝트를 통째로 다른 PC에 옮기려면 이 **폴더를 복사**하세요.
- 아래 막대의 칩이 저장 상태를 보여 줍니다. **"저장 안 됨 · 자동 저장 12:03"** 처럼 마지막 자동 저장 시각도 나오고, 누르면 저장합니다.
- 메뉴 **[파일] ▸ [프로젝트 폴더 열기]** 로 폴더를 엽니다.

## 자동 저장과 복구

저장하지 않아도 **1분마다 복구용으로 자동 저장**됩니다. 프로그램이 비정상 종료되면 다음에 켤 때 **복구할지 묻습니다.** 자동 저장은 비정상 종료에 대비한 임시 복구용이니, 꼭 **Ctrl+S로 저장**하세요.

## 되돌리기

**Ctrl+Z** 되돌리기, **Ctrl+Y** 다시 실행. 채팅창 초기화, 프리셋 적용도 되돌릴 수 있습니다.

## 초기화

| 하고 싶은 것 | 방법 |
|---|---|
| 요소의 회전·투명도·반전 되돌리기 | 설정의 **[모양 초기화]** |
| 요소의 효과 끄기 | **[효과 모두 끄기]** |
| 문구 모양 되돌리기 | **[글자 모양 초기화]** (내용·시각은 유지) |
| 채팅창 설정 되돌리기 | **[기본값으로 초기화]** |
| 접어 둔 패널, 마지막 폴더 등 화면 설정 | **[도움말] ▸ [화면 설정 초기화…]** (프로젝트·키·로그인은 건드리지 않음) |

## 데이터가 저장되는 곳

| 위치 | 내용 |
|---|---|
| 내가 고른 폴더 | 프로젝트(`project.json` + `media`) |
| `%AppData%\StandbyScreen` | 최근 프로젝트, 채팅 프리셋, 설정, 자동 저장, 로그 |
| `%AppData%\StandbyScreen\user-templates` | 내 템플릿 |
| `%AppData%\StandbyScreen\donations` | 후원 기록 |
| `%AppData%\StandbyScreen\logs` | 문제 확인용 로그 |
| `%LocalAppData%\StandbyScreen` | **암호화된** 앱 키·로그인 정보 (`*.bin`) |

`%AppData%` 는 탐색기 주소창에 그대로 입력하면 열립니다.

## 다른 PC로 옮기기

- 프로젝트 폴더를 복사해서 열면 됩니다.
- **앱 키와 로그인 정보는 PC마다 따로** 입력해야 합니다. 암호화되어 그 PC에서만 풀립니다.
- 내 소리 파일(YouTube 알림음)은 고른 경로를 그대로 쓰므로 다시 골라야 합니다.

## 로그 보내기

문제가 생겼을 때 **[도움말] ▸ [로그 내보내기…]** 로 파일을 만들어 판매자에게 보냅니다. 키·토큰·로그인 정보는 가려진 채로 기록됩니다. 후원 원본 로그는 여기에 포함되지 않습니다.
