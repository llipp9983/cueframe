# 설치와 Windows 경고

처음 설치할 때 Windows가 **파란색 경고 화면**을 보여 줍니다. 아래 순서대로 하면 설치할 수 있습니다.

:::summary 한눈에 보기
- 파란 **Windows 경고는 정상**입니다 (서명이 없는 개인 프로그램이라 뜨는 일반 경고, 바이러스 아님)
- 넘기는 법: **[추가 정보]** ▸ **[실행]**
- 받은 곳은 **판매자가 알려 준 주소**뿐, 불안하면 **해시로 확인**
- 관리자 권한 필요 없음, 약 5분
:::


## 1. 받기

판매자가 알려 준 주소(GitHub 릴리즈 페이지)에서 아래 파일 중 **하나**만 받습니다.

| 파일 | 설명 |
|---|---|
| `CUEFRAME-버전-win-x64.exe` | **설치 파일 (권장)**. 시작 메뉴·바탕화면에 아이콘이 생기고, 새 버전이 나오면 알려 줍니다. |
| `CUEFRAME-버전-win-x64.zip` | 설치 없이 압축만 풀어서 쓰는 방식. 설치 파일이 막힐 때 대신 씁니다. 자동 업데이트는 되지 않습니다. |
| `CUEFRAME-버전-portable.exe` | **포터블 (설치 없이 실행)**. 파일 하나를 받아 더블클릭하면 실행됩니다. 자동 업데이트는 되지 않으니, 새 버전이 나오면 새 파일로 바꿔 주세요. |

> **주의** 다른 사이트나 메신저로 전달받은 파일은 열지 말고, **판매자가 알려 준 주소에서만** 받으세요.

브라우저(Edge·Chrome)가 "흔히 다운로드되지 않는 파일입니다"라고 물으면, 위 주소에서 받은 파일이 맞다면 **[유지]** 를 누릅니다.

## 2. 설치하기

1. 받은 `.exe`를 더블클릭합니다.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 아래 3번을 따라 합니다.
3. 설치 마법사에서 **[다음]** ▸ 설치할 폴더 확인 ▸ **[설치]**. 관리자 권한은 필요하지 않습니다.
4. 끝나면 **[마침]**, 바탕화면의 **CUEFRAME** 아이콘으로 실행합니다.

## 3. Windows 경고 넘기기

### 왜 뜨나요?

- 이 프로그램에는 **디지털 서명**(제작자를 Microsoft에 증명하는 유료 인증서)이 없습니다. 개인이 만든 프로그램은 비용 때문에 서명 없이 배포되는 경우가 많습니다.
- Windows는 게시자를 "알 수 없음"으로 보고, 아직 다운로드한 사람이 많지 않은 프로그램에 일단 이 경고를 보여 줍니다.
- **바이러스가 발견되었다는 뜻이 아닙니다.**
- 다만 "믿을 수 있는지 모른다"는 뜻이므로, **판매자에게서 받은 파일이 맞을 때만** 넘어가세요. 아래 "파일이 맞는지 확인하기"를 권장합니다.

### 넘기는 방법

아래 그림은 이해를 돕기 위한 **예시 화면**입니다. Windows 버전에 따라 모양이 조금 다를 수 있습니다.

1. 경고 창에서 **[추가 정보]** 를 누릅니다.

![SmartScreen 경고 창: 추가 정보를 누릅니다](img/smartscreen-1.png)

2. **[실행]** 버튼이 나타납니다. 게시자가 "알 수 없는 게시자"로 보이는 것이 정상입니다. **[실행]** 을 누르면 설치가 시작됩니다.

![[실행] 버튼을 누르면 설치가 시작됩니다](img/smartscreen-2.png)

새 버전으로 업데이트할 때 같은 경고가 다시 나올 수 있습니다. 같은 방법으로 넘기면 됩니다.

## 4. 그래도 안 될 때

### [실행] 버튼이 안 보여요
회사·학교 PC이거나 보안 정책이 강한 PC입니다. 개인 PC에서 시도하거나 PC 관리자에게 문의하세요.

### zip으로 쓰는데 실행이 안 돼요
인터넷에서 받은 zip에는 "차단됨" 표시가 붙을 수 있습니다. **압축을 풀기 전에** zip 파일을 오른쪽 클릭 ▸ **속성** ▸ 아래쪽 **[차단 해제]** 체크 ▸ **[확인]** 한 뒤 압축을 풀고 `CUEFRAME.exe`를 실행합니다.

![zip 파일 속성에서 차단 해제를 체크합니다 (예시 화면)](img/zip-unblock.png)

### 백신이 파일을 지우거나 격리했어요
서명이 없는 새 프로그램은 백신이 의심하는 일(오탐)이 있습니다. 백신의 격리 목록에서 **복원**하고 **예외 목록에 추가**한 뒤 다시 설치하세요. Windows 보안은 `바이러스 및 위협 방지` ▸ `보호 기록` ▸ 해당 항목 ▸ `작업` ▸ `허용` 입니다.

## 5. 파일이 맞는지 확인하기 (선택, 권장)

판매자가 올린 파일이 중간에 바뀌지 않았는지 **SHA-256 해시**로 확인할 수 있습니다. 받은 파일이 있는 폴더에서 PowerShell을 열고 입력합니다. (파일 이름은 받은 파일에 맞게 바꾸세요.)

```
Get-FileHash .\CUEFRAME-1.9.3-win-x64.exe -Algorithm SHA256
```

## 6. 업데이트와 삭제

- **업데이트**: 설치 파일로 설치했다면 새 버전이 나올 때 프로그램 안에 알림이 뜹니다. 만들어 둔 프로젝트는 그대로 남습니다.
- **삭제**: Windows `설정` ▸ `앱` ▸ `설치된 앱`에서 **CUEFRAME** ▸ 제거. (zip은 폴더를 지우면 됩니다.)
- 프로젝트 파일은 직접 고른 폴더에 있어 삭제해도 남습니다. 완전히 지우려면 [저장·복구·데이터 위치](files.md)의 폴더도 지우세요.
