# OBS에 넣기

CUEFRAME은 방송용 **출력 창**을 따로 열고, OBS가 그 창을 **창 캡처**로 가져갑니다.

:::summary 한눈에 보기
1. **[출력 창 열기]**
2. OBS ▸ **＋** ▸ **[창 캡처]** ▸ `[CUEFRAME.exe]: 방송 출력 창`
3. 방식 **Windows 10 (1903 이상)**, 커서 캡처 **끄기**

출력 창은 **최소화하지 말고 [-]** 를 쓰세요.
:::


## 순서

1. CUEFRAME 오른쪽 아래 **[출력 창 열기]** 를 누릅니다. **"방송 출력 창"** 이 열립니다.
2. OBS의 소스 목록에서 **＋** ▸ **[창 캡처]** 를 추가합니다.
3. 창 항목에서 `[CUEFRAME.exe]: 방송 출력 창`을 고릅니다.
4. 캡처 방식은 **Windows 10 (1903 이상)**, **커서 캡처는 끕니다.**

출력 창이 다른 창에 가려져도 캡처됩니다.

## 알아 둘 것

- 출력 창을 **최소화하면 화면이 멈춥니다.** 최소화 대신 출력 창의 **[-]** 버튼을 쓰세요. 창이 화면 밖으로 숨겨집니다. 숨긴 상태에서도 OBS는 계속 화면을 가져갑니다. 되돌리려면 아래쪽의 **[출력 창 다시 띄우기]** 를 누르거나, 작업 표시줄의 **[방송 출력 창]** 을 누르면 화면 안으로 올라옵니다. 출력 창을 닫았다 다시 열면 마지막에 닫았던 **크기와 위치 그대로** 열립니다.
- 출력 해상도(1920×1080 / 1280×720)는 **[⚙ 출력 설정]** 에서 바꿉니다. **OBS 캔버스와 같게 맞추면 가장 선명합니다.**
- 프레임 수는 30fps 또는 60fps입니다. PC가 힘들어하면 30fps로 두세요.
- 출력 창을 **줄여서** 쓸 수 있습니다. 한 번 줄여 두면 전환 효과 같은 옵션을 바꿔도 크기가 유지됩니다. (해상도를 바꾸면 가로는 유지하고 세로만 새 비율에 맞춥니다.)
- 출력 창이 열려 있을 때 하단 버튼은 **"출력 중 · 닫기"** 로 바뀝니다.

## 출력 설정

![출력 설정 팝업](img/output-settings.png)

| 항목 | 설명 |
|---|---|
| 해상도 | 1920×1080 / 1280×720 |
| 프레임 수 | 30fps / 60fps |
| 장면 전환 | 장면이 바뀔 때의 효과. 고르면 아래에 **A ↔ B 미리보기**가 계속 돕니다. ([장면과 전환 효과](scenes.md)) |
| 진단 표시 | 출력 창에 실제 fps를 보여 줍니다. |

도움말 메뉴의 **[OBS 설정 안내]** 에도 같은 내용이 있습니다.
