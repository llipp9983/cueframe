# 5분 만에 시작하기


:::summary 한눈에 보기
1. **[템플릿으로 시작]** 으로 디자인 고르기
2. 문구와 카운트다운 시각 바꾸기
3. (선택) 채팅 연결
4. **[출력 창 열기]** ▸ OBS **창 캡처**
5. **Ctrl+S** 저장
:::

## 1. 템플릿으로 시작하기

프로그램을 처음 켜면(열어 둔 프로젝트가 없으면) **시작 화면**이 뜹니다.

![시작 화면](img/start.png)

- **[템플릿으로 시작]**: 완성된 대기화면을 큰 예시로 보고 고릅니다. 가장 빠릅니다.
- **[빈 화면으로 시작]**: 아무것도 없는 화면에서 직접 만듭니다.
- 최근에 열었던 프로젝트가 있으면 아래에 보입니다.

템플릿 카드를 누르면 큰 미리보기 창이 열리고, 거기서 **[이 템플릿으로 시작]** 을 누르면 배경, 소품, 문구, 채팅창, 움직임이 한 번에 만들어집니다. 장면이 2개("대기 중", "곧 시작") 들어 있습니다.

![템플릿 고르기](img/templates.png)

> **참고** 시작 화면 대신 위쪽 메뉴 **[파일] ▸ [템플릿으로 새 프로젝트…]** 로도 같은 창을 열 수 있습니다.

## 2. 문구와 시간 바꾸기

- 미리보기에서 문구를 클릭하면 오른쪽에 설정이 나옵니다. 내용, 글꼴, 색을 바꿉니다.
- **카운트다운**은 방송 시작 시각을 정해 두면 남은 시간이 줄어듭니다.
- 소품은 끌어서 옮기고, 모서리 손잡이로 크기를 바꿉니다.

## 3. 채팅 연결 (선택)

화면 오른쪽 아래 **[채팅 연결하기]** 로 치지직·YouTube·SOOP을 연결합니다. 나중에 해도 됩니다. 자세한 방법은 [채팅 연결 (로그인)](chat-connect.md)입니다.

## 4. 출력 창 열고 OBS에 넣기

1. 오른쪽 아래 **[출력 창 열기]** 를 누릅니다.
2. OBS에서 소스 **[창 캡처]** 로 "방송 출력 창"을 고릅니다.

자세한 설정은 [OBS에 넣기](obs.md)입니다.

## 5. 저장하기

**Ctrl+S** 로 저장합니다. 저장하지 않아도 1분마다 복구용으로 자동 저장되지만, 이것은 프로그램이 비정상 종료됐을 때 되살리는 용도입니다. 자세한 내용은 [저장·복구·데이터 위치](files.md)입니다.

> **팁** 도움말 메뉴의 **[시작하기 안내]** 에도 그림이 들어 있는 짧은 안내가 있습니다.
