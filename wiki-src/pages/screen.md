# 화면 구성


:::summary 한눈에 보기
- **왼쪽** 레이어 목록 · **가운데** 미리보기 · **오른쪽** 설정 · **아래** 추가/도구/출력 버튼
- 요소는 **끌어서** 이동, **손잡이**로 크기·회전
- 하단 칩으로 **저장 상태**와 **채팅 연결 상태**를 확인
:::

![편집기 화면](img/editor.png)

## 크게 보면

| 위치 | 이름 | 하는 일 |
|---|---|---|
| 맨 위 | 메뉴 | **파일**(새 프로젝트, 템플릿, 열기, 저장), **편집**(되돌리기, 복제 등), **도움말** |
| 왼쪽 | 레이어 목록 | 화면에 올라간 요소들. **위쪽이 앞**에 보입니다. 눈 아이콘은 숨김, 자물쇠는 잠금 |
| 가운데 위 | 장면 탭과 정렬 막대 | 장면 전환, 요소 정렬·스냅 |
| 가운데 | 미리보기 | 요소를 끌어 옮기고, 손잡이로 크기·회전을 바꿉니다 |
| 오른쪽 | 설정 패널 | 고른 요소의 상세 설정 |
| 맨 아래 | 하단 막대 | 되돌리기, **＋ 추가**, 저장 상태, 채팅 상태, **도구**, **출력 설정**, **출력 창 열기** |

## 아무것도 고르지 않았을 때: 방송 준비 카드

오른쪽 설정 패널은 요소를 고르지 않으면 **방송 준비 카드**가 됩니다. 출력 창, 채팅 연결, 후원 알림 칸, 저장 상태를 한곳에서 확인하고, 옆 버튼으로 바로 고칠 수 있습니다. 아래 **[자주 하는 일]** 에는 템플릿 고르기, 배경 설정, 소품·문구·채팅창 추가 버튼이 있습니다.

![방송 준비 카드](img/ready-panel.png)

## 미리보기에서

- 요소를 **끌면** 이동, 모서리 **네모 손잡이**로 크기, 위쪽 **동그란 손잡이**로 회전합니다.
- 이미지 파일을 미리보기로 **끌어다 놓으면** 요소로 추가됩니다.
- 화살표 키는 1칸, **Shift+화살표**는 10칸 이동합니다.
- 숫자 키 `1`~`9`, `0`은 선택한 요소의 투명도(10%~90%, 100%)입니다.

## 레이어 목록에서

- 끌어서 순서를 바꿉니다.
- **F2** 로 이름을 바꿉니다.
- 눈 아이콘으로 숨기고, 자물쇠로 잠가서 실수로 움직이지 않게 합니다.
- 아래 버튼으로 앞/뒤로 보내기, 복제, 삭제를 합니다.

## 하단 막대

![추가 메뉴](img/add-menu.png)

- **＋ 추가**: 요소를 추가합니다. ([요소 추가하기](elements.md))
- **저장 상태 칩**: "저장 안 됨 · 자동 저장 12:03" / "저장됨" / "새 프로젝트". 누르면 저장합니다.
- **파일 N개 없음** 경고: 누르면 그 요소로 이동합니다. 옮기거나 지운 그림 파일을 다시 지정하세요.
- **채팅 연결하기 / 연결됨** 칩: 누르면 채팅 연결 창이 열립니다.
- **도구 ▾**: 방송 리모컨, 방송 중 잠금, 장면 단축키, 샘플 채팅, 채팅 비우기.

![도구 메뉴](img/tools-menu.png)

- **⚙ 출력 설정**: 해상도, 프레임 수, 장면 전환 효과.
- **출력 창 열기**: 방송용 창을 엽니다. 열려 있으면 "출력 중 · 닫기"로 바뀝니다.

## 정렬 막대

위쪽 막대에서 여러 요소를 왼쪽/가운데/오른쪽, 위/가운데/아래로 맞추고 같은 간격으로 늘어놓을 수 있습니다. **스냅**을 켜면 끌 때 가장자리와 중앙에 달라붙습니다.
