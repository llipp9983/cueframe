# 단축키 모음

프로그램 안에서는 **[도움말] ▸ [단축키 보기]** 로도 볼 수 있습니다.

## 파일

| 키 | 동작 |
|---|---|
| Ctrl+N | 새 프로젝트 |
| Ctrl+O | 열기 |
| Ctrl+S | 저장 |
| Ctrl+Shift+S | 다른 이름으로 저장 |

## 편집

| 키 | 동작 |
|---|---|
| Ctrl+Z | 되돌리기 |
| Ctrl+Y | 다시 실행 |
| Ctrl+D | 복제 |
| Ctrl+A | 모두 선택 |
| Ctrl+H | 좌우 반전 (소품·테이블) |
| Delete | 삭제 |
| F2 | 레이어 이름 바꾸기 (요소 1개 선택 시) |
| 방향키 | 선택한 요소를 1칸 이동 |
| Shift+방향키 | 10칸 이동 |
| 숫자 1~9, 0 | 선택한 요소의 투명도 10%~90%, 100% |
| Ctrl+클릭 | 여러 요소 선택 |

## 장면과 방송

| 키 | 동작 |
|---|---|
| Ctrl+1 ~ 9 | 편집할 장면 전환 |
| Alt+1 ~ 9 | 해당 번째 장면을 방송에 내보냄 |
| Ctrl+Alt+1 ~ 9 | 같은 동작, 다른 프로그램을 쓰는 중에도 (**[도구] ▸ [장면 단축키]** 를 켠 경우) |
| Ctrl+L | 방송 중 잠금 켜기/끄기 |

> **참고** 방송 중 잠금이 켜져 있으면 편집 단축키는 동작하지 않고, **Alt+1~9** 와 **Ctrl+L** 만 동작합니다.

## 검색

이 설명서에서는 `/` 키로 검색창으로 이동합니다.
