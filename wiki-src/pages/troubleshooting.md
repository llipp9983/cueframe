# 문제 해결

증상에서 찾아보세요. 해결이 안 되면 마지막의 "판매자에게 문의할 때"를 보세요.

:::summary 먼저 이것부터
- 후원이 안 뜸 → 치지직 **후원 조회** 권한, 그리고 **출력 창**에서 확인
- OBS 화면이 멈춤 → 출력 창을 **최소화**하지 않았는지
- 해결이 안 되면 **[도움말] ▸ [로그 내보내기…]** 파일을 판매자에게
:::


## 설치·실행

| 증상 | 확인할 것 |
|---|---|
| 설치할 때 파란 경고가 뜸 | 정상입니다. [설치와 Windows 경고](install.md)를 보세요. |
| 백신이 파일을 지움 | 오탐입니다. 격리 목록에서 복원하고 예외에 추가하세요. ([설치와 Windows 경고](install.md)) |
| zip으로 받았는데 실행 안 됨 | 압축을 풀기 전에 zip 속성에서 **차단 해제**를 하세요. |
| 켜자마자 꺼짐 | 작업 관리자에서 `CUEFRAME`을 완전히 종료하고 다시 실행하세요. 그래도 안 되면 `%AppData%\StandbyScreen\logs` 의 `.log` 파일을 판매자에게 보내세요. |

## 출력 창·OBS

| 증상 | 확인할 것 |
|---|---|
| OBS에 창이 안 보임 | **[출력 창 열기]** 를 눌렀는지. 소스는 **[창 캡처]** 이고 창 이름은 `[CUEFRAME.exe]: 방송 출력 창` |
| OBS 화면이 멈춤 | 출력 창을 **최소화**했을 가능성이 큽니다. 최소화 대신 **[-]** 를 쓰고, 되돌리려면 **[출력 창 다시 띄우기]** |
| 화면이 흐릿함 | 출력 해상도를 OBS 캔버스와 같게 맞추세요. |
| 화면이 끊김 | **[⚙ 출력 설정]** 에서 30fps로 낮추고, 큰 영상 배경이나 효과를 줄이세요. **[진단 표시]** 로 fps를 확인하세요. |
| 출력 창이 자꾸 커짐 | 1.8.0 이상에서는 고쳐졌습니다. 업데이트하세요. |

## 채팅 연결

| 증상 | 확인할 것 |
|---|---|
| 치지직 로그인 후 돌아오지 않음 | 리디렉션 URL이 `http://localhost:51789/callback` 와 한 글자도 다르지 않은지. 다른 프로그램이 51789번 포트를 쓰고 있지 않은지. |
| "채팅 조회 권한이 없습니다" | 앱 권한에 **채팅 메시지 조회**가 있는지. |
| YouTube가 갑자기 안 됨 | 간편 연결은 비공식입니다. **공식 API**로 바꿔 보세요. 업데이트도 확인하세요. |
| SOOP이 연결 안 됨 | 방송 중인지, 19세 이상·비밀번호 방송이 아닌지. 방송인 ID 철자를 확인하세요. |
| 다른 PC에서 로그인이 풀려 있음 | 정상입니다. 키·로그인은 PC마다 따로 입력합니다. |

## 후원

| 증상 | 확인할 것 |
|---|---|
| 채팅은 나오는데 **치지직 후원이 안 뜸** | 앱 권한에 **후원 조회**가 있는지. 켠 뒤 **다시 연결**해야 합니다. 상태에 "후원 알림 권한 없음"이 보이면 이 경우입니다. |
| 알림이 안 보임 | 알림은 **방송 출력 창에서만** 움직입니다. **[출력 창 열기]** 후 확인하세요. **후원 알림 칸**을 추가했는지, **최소 금액**이 너무 높지 않은지도 보세요. |
| 연결 직후 예전 후원이 안 뜸 | 연결할 때 딸려 오는 **30초 넘은 지난 후원은 띄우지 않습니다.** |
| 소리가 안 남 | 소리·읽어 주기는 **YouTube 후원에만** 적용됩니다. 치지직·SOOP은 방송 사이트 위젯의 소리를 쓰세요. |
| 후원이 이상하게 보임 | **[후원 기록·문제 확인] ▸ [받은 후원 원본을 로그로 남기기]** 를 켜고 다시 받아 보세요. `%AppData%\StandbyScreen\logs\donation-raw.txt` 에 쌓입니다. |
| 후원이 한꺼번에 몰려 뜸 | 겹친 후원은 **차례로** 뜹니다. 방송 리모컨에서 **[지금 알림 넘기기]** 를 쓰세요. |

## 편집

| 증상 | 확인할 것 |
|---|---|
| 요소가 안 움직임 | 레이어의 **자물쇠**가 잠겨 있는지, **방송 중 잠금**이 켜져 있는지 (위쪽 🔒 띠). |
| "파일 N개 없음" | 그림·영상 파일을 옮기거나 지운 것입니다. 누르면 그 요소로 이동하니 **[파일 다시 연결…]** 로 지정하세요. |
| 잘못 지움 | **Ctrl+Z**. 비정상 종료라면 다음 실행 때 복구를 선택하세요. |
| 전환 효과가 안 보임 | 장면이 2개 이상이어야 하고, **[⚙ 출력 설정]** 의 전환이 "바로 바꾸기"가 아닌지 확인하세요. |

## 판매자에게 문의할 때

아래를 함께 보내 주시면 빠르게 해결할 수 있습니다.

1. **Windows 버전**, **프로그램 버전** (**[도움말] ▸ [정보]**)
2. **화면에 나온 문구나 캡처**
3. **[도움말] ▸ [로그 내보내기…]** 로 만든 파일. 키·토큰은 가려져 있습니다.
4. 후원 문제라면, 어느 플랫폼의 어떤 후원이었는지
